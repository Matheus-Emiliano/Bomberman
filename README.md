# Desafio-ia

Projeto **Bomberman MDP 4-Bot Battle** — uma simulação visual de Aprendizado por Reforço / Processo de Decisão de Markov (MDP) com quatro agentes.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador moderno.
3. Use os controles da interface para pausar, reiniciar e acompanhar os bots. Para controle manual do Bot 1, ative o modo manual na interface.

> A interface usa Tailwind CSS, Font Awesome e Google Fonts por CDN; é necessária conexão com a internet para carregar esses recursos externos.

## Arquivos

- `index.html` — jogo e visualizador interativo.
- `Desafio-1-Bomberman-4-Bot-MDP.pdf` — documento do desafio.
