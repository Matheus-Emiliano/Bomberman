## Sobre o projeto

O **Bomberman — MDP 4-Bot Battle** é uma demonstração interativa inspirada em jogos de arena no estilo Bomberman. O projeto apresenta uma arena com quatro bots e permite acompanhar suas ações enquanto eles se movimentam e utilizam bombas.

A proposta é aproximar conceitos de **inteligência artificial** e **Processos de Decisão de Markov (MDP)** de uma experiência visual e prática.

##  Destaques

- **Arena estilo Bomberman:** cenário com movimentação e bombas.
-  **Quatro bots:** agentes que participam da simulação.
-  **Conceitos de MDP:** exploração de decisões em um ambiente dinâmico.
-  **Controles interativos:** opções na interface para acompanhar e controlar a simulação.
-  **Direto no navegador:** não é necessário instalar um programa específico.

##  Como executar

1. Baixe este repositório ou clone-o.
2. Abra o arquivo `index.html` em um navegador atualizado.
3. Utilize os controles disponíveis na interface para explorar os modos e acompanhar a simulação.

> **Observação:** alguns recursos visuais são carregados por serviços externos (CDNs). É necessária uma conexão com a internet para que esses recursos sejam carregados corretamente.

## O que é MDP?

Um **Processo de Decisão de Markov (MDP)** é um modelo usado para representar situações em que um agente observa um estado, escolhe uma ação e recebe um resultado. Em uma arena, esse conceito pode ajudar a estudar decisões como movimentação, posicionamento e uso de recursos.

Esta é uma apresentação geral do conceito; os detalhes específicos da implementação devem ser consultados no código e no documento do desafio.
